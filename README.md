# Many Lives

A life-simulator game. Create a character at 18 with $5,000 and age up year by year. Each year you get 3 actions (gym, study, jobs, college, investing...) and random events that force a choice.

## Run locally
- Easiest: open `index.html` in a browser.
- Or: `npm start`, then visit http://localhost:3000

## Deploy
Push to GitHub, then Settings > Pages > Deploy from branch `main` (root). No build step needed.

## Extend it
- Events: add entries to `EVENTS` in `game.js`
- Jobs: edit `JOBS`
- Actions: edit `ACTIONS`
